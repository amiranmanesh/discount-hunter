کمپین `تخفیف نارنجی` اسنپ‌مارکت و `شگفت‌انگیز` دیجی‌کالا جت هم‌زمان روی ده‌ها
فروشگاه اجرا می‌شوند و یک کالای مشخص در هرکدام تخفیف متفاوتی دارد. این برنامه هر
دو را با حساب خودت می‌خواند و همه‌چیز را بر اساس عمق واقعی تخفیف مرتب می‌کند.

دو راه استفاده:

- **تخفیف‌ها** — فید بی‌پایان همهٔ پیشنهادهای کمپینی محدوده‌ات، بیشترین تخفیف
  اول، مخلوط از هر دو پلتفرم. چیزی برای تایپ کردن نیست.
- **جستجو** — یک کالا، قیمت‌گذاری‌شده در همهٔ فروشگاه‌هایی که به تو ارسال دارند،
  مرتب بر اساس تخفیف، بعد **پرو** اسنپ‌مارکت، بعد هزینهٔ ارسال.

پروژه‌ای مستقل و متن‌باز است و هیچ وابستگی‌ای به اسنپ یا دیجی‌کالا ندارد.

## فقط قیمتی که واقعاً می‌توانی بپردازی

سه قانون، که هرکدام چون یک بار اشتباه شد وجود دارند:

- **قفسهٔ «ویژه خرید اول» اصلاً خوانده نمی‌شود.** هر تخفیف ۹۰ تا ۹۹ درصدی در فید
  کمپین اسنپ‌مارکت مخصوص حساب تازه‌ساخته است. این قیمت‌ها برای حساب قدیمی وجود
  ندارند، پس آن باکت اصلاً گرفته نمی‌شود — فقط شمرده می‌شود تا برنامه بگوید چه
  چیزی را نادیده گرفت.
- **نتایج جستجو قبل از نمایش با قفسهٔ خود فروشگاه تأیید می‌شوند**، با توکن تو و
  با همان درخواستی که صفحهٔ فروشگاه می‌زند. چیزی که فروشگاه لیست نکرده باشد حذف
  می‌شود، نه اینکه نمایش داده شود.
- **حالت مهمان وجود ندارد.** مهمان کمپین دیگری با قیمت دیگری می‌بیند، پس جستجو
  بدون نشست اسنپ‌مارکت تو اجرا نمی‌شود.

## اجرا

```bash
git clone https://github.com/amiranmanesh/discount-hunter.git
cd discount-hunter
npm ci
npm run build
npm start          # → http://localhost:4173
```

روی موبایل در همان شبکه بازش کن و به صفحهٔ اصلی اضافه کن؛ مثل یک اپ مستقل نصب
می‌شود.

برای توسعه، `npm run dev` همین را روی ۵۱۷۳ با hot reload می‌دهد.

### چرا سرور لازم دارد

هیچ‌کدام از دو پلتفرم درخواست cross-origin از مرورگر را قبول نمی‌کنند —
اسنپ‌مارکت `Access-Control-Allow-Origin` را فقط برای سایت خودش می‌فرستد و
دیجی‌کالا جت اصلاً نمی‌فرستد — پس صفحه نمی‌تواند مستقیم صدایشان بزند، هر کدی هم
که بنویسی. برای همین برنامه همراه یک پروکسی سادهٔ هم‌مبدأ سرو می‌شود. پروکسی
چیزی نگه نمی‌دارد، ولی سر راه است؛ پس خودت اجرایش کن —
[docs/PRIVACY.md](docs/PRIVACY.md) صریح دربارهٔ این معامله نوشته.

## ورود به حساب

**حساب‌ها** ← شماره موبایل ← کد پیامکی، هر پلتفرم جدا.

**اسنپ‌مارکت اجباری است.** **دیجی‌کالا جت اختیاری**: جستجویش توکن نمی‌خواهد و
ورود فقط آدرس‌های ذخیره‌شدهٔ آن حساب را اضافه می‌کند. برنامه refresh token خودش
را نگه می‌دارد، پس نشست خودش تمدید می‌شود و بعد از یک ساعت نمی‌میرد.

کدها عمداً محدود شده‌اند: ۲ دقیقه بین دو کد، ۵ کد در ۱۵ دقیقه، ۵ تلاش برای هر
کد، و `Retry-After` سرور رعایت می‌شود.

## تنظیم موقعیت تحویل

**تنظیمات** ← **استفاده از موقعیت فعلی** برای GPS، یا مختصات را دستی وارد کن.
اگر به جت وارد شده باشی، آدرس‌های ذخیره‌شده‌ات هم همان‌جا لیست می‌شود.

## ساختار

```
src/api/        یک کلاینت برای هر پلتفرم؛ هرچه با شبکه کار دارد
src/core/       فید، جستجو، رتبه‌بندی، تطبیق فارسی — همه بدون I/O
src/auth/       نشست، محدودیت نرخ OTP، نرمال‌سازی شماره
src/routes/     یک فایل برای هر تب
server/         سرور پروداکشن و جدول مشترک پروکسی
docs/           معماری، اندپوینت‌ها، حریم خصوصی، توسعه
```

React 19، Vite 8، TypeScript، TanStack Query، zustand و `vite-plugin-pwa`. بدون
فریم‌ورک UI: حدود ۷۰۰ خط CSS با توکن‌های طراحی، RTL، تم روشن و تیره از سیستم، و
نوار پایینی روی موبایل که روی لپ‌تاپ به نوار بالایی تبدیل می‌شود.

## مشارکت

مفیدترین گزارش، تغییر شکل یک اندپوینت است — این‌ها APIهای مستندنشده‌اند و بدون
اطلاع عوض می‌شوند. [CONTRIBUTING.md](CONTRIBUTING.md) را ببین، و **هیچ‌وقت هدر
`Authorization` را جایی نچسبان**: آن توکن یعنی حساب تو.
