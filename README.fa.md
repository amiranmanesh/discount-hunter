کمپین `تخفیف نارنجی` اسنپ‌مارکت، `شگفت‌انگیز` دیجی‌کالا جت و کاروسل‌های تخفیف
اوکالا هم‌زمان روی ده‌ها فروشگاه اجرا می‌شوند و یک کالای مشخص در هرکدام تخفیف
متفاوتی دارد. این برنامه هر سه را با حساب خودت می‌خواند و همه‌چیز را بر اساس عمق
واقعی تخفیف مرتب می‌کند.

سه راه استفاده:

- **تخفیف‌ها** — فید بی‌پایان همهٔ پیشنهادهای کمپینی محدوده‌ات، بیشترین تخفیف
  اول، مخلوط از هر سه پلتفرم. چیزی برای تایپ کردن نیست.
- **جستجو** — یک کالا، قیمت‌گذاری‌شده در همهٔ فروشگاه‌هایی که به تو ارسال دارند،
  مرتب بر اساس تخفیف، بعد **پرو** اسنپ‌مارکت، بعد هزینهٔ ارسال.
- **سبد** — چیزهایی که می‌خواهی بخری، و ارزان‌ترین راه خریدن همه‌شان: هر کالا از
  کدام فروشگاهِ کدام پلتفرم، در یک، دو یا سه سفارش، با هزینهٔ ارسال، هزینهٔ خدمات و
  حداقل سبد هر فروشگاه. یک کالا در پلتفرم‌های مختلف با عنوان و حجمش — سخت‌گیرانه —
  شناخته می‌شود و هر تطبیق با یک لمس رد می‌شود.

پروژه‌ای مستقل و متن‌باز است و هیچ وابستگی‌ای به اسنپ یا دیجی‌کالا ندارد.

## فقط قیمتی که واقعاً می‌توانی بپردازی

چهار قانون، که هرکدام چون یک بار اشتباه شد وجود دارند:

- **قفسهٔ «ویژه خرید اول» اصلاً خوانده نمی‌شود.** هر تخفیف ۹۰ تا ۹۹ درصدی در فید
  کمپین اسنپ‌مارکت مخصوص حساب تازه‌ساخته است. این قیمت‌ها برای حساب قدیمی وجود
  ندارند، پس آن باکت اصلاً گرفته نمی‌شود — فقط شمرده می‌شود تا برنامه بگوید چه
  چیزی را نادیده گرفت.
- **نتایج جستجو قبل از نمایش با قفسهٔ خود فروشگاه تأیید می‌شوند**، با توکن تو و
  با همان درخواستی که صفحهٔ فروشگاه می‌زند. چیزی که فروشگاه لیست نکرده باشد حذف
  می‌شود، نه اینکه نمایش داده شود.
- **حالت مهمان وجود ندارد.** مهمان کمپین دیگری با قیمت دیگری می‌بیند، پس
  اسنپ‌مارکت به‌جای جستجوی ناشناس کنار گذاشته می‌شود و برنامه همین را می‌گوید.
  جستجوی اوکالا هم توکن خودش را می‌خواهد؛ دیجی‌کالا جت نمی‌خواهد.
- **هزینه همان هزینه‌ای است که می‌پردازی.** ارسال ارزان فروشگاه‌های «پرو»
  اسنپ‌مارکت فقط برای مشترک اسنپ پرو است، پس بدون اشتراک (کلیدی در **تنظیمات**)
  هزینهٔ کامل حساب می‌شود؛ هزینهٔ خدمات و بسته‌بندی اوکالا حساب می‌شود؛ و هزینهٔ
  ارسالی که فهرستی نگفته باشد پرسیده می‌شود، نه اینکه رایگان خوانده شود.

## اجرا

**با داکر، یک دستور:**

```bash
docker run -p 3000:3000 ghcr.io/amiranmanesh/discount-hunter:latest
```

یا `docker compose up -d` با [`compose.yaml`](compose.yaml) همین ریپو.

**از سورس:**

```bash
git clone https://github.com/amiranmanesh/discount-hunter.git
cd discount-hunter
npm ci
npm run build
npm start          # → http://localhost:3000
```

`npm run dev` همین برنامه را روی همان پورت با hot reload بالا می‌آورد.

روی موبایل در همان شبکه بازش کن و به صفحهٔ اصلی اضافه کن؛ مثل یک اپ مستقل نصب
می‌شود.

**روی دامنهٔ خودت**، پشت یک ریورس‌پروکسی بگذارش که TLS را تمام کند و همه‌چیز —
از جمله `/api/*` — را به کانتینر بدهد. هیچ مبدأ، مسیر پایه یا آدرس بازگشتی‌ای
برای تنظیم‌کردن وجود ندارد، چون صفحه و پروکسی‌اش یک سرور واحدند. بلوک‌های آمادهٔ
nginx و Caddy و Traefik و فهرست کامل متغیرها (که همه‌شان اختیاری‌اند) در
[`docs/DEPLOY.md`](docs/DEPLOY.md).

### چرا سرور لازم دارد

هیچ‌کدام از سه پلتفرم درخواست cross-origin از مرورگر را قبول نمی‌کنند —
اسنپ‌مارکت `Access-Control-Allow-Origin` را فقط برای سایت خودش می‌فرستد،
دیجی‌کالا جت اصلاً نمی‌فرستد و اوکالا در پاسخ واقعی حذفش می‌کند — پس صفحه
نمی‌تواند مستقیم صدایشان بزند، هر کدی هم که بنویسی. برای همین برنامه یک سرور
Next.js است: همان پراسسی که صفحه را رندر می‌کند، `/api/*` را هم از سمت سرور
فوروارد می‌کند، جایی که اصلاً قاعدهٔ cross-origin معنا ندارد. دقیقاً به همین دلیل
روی `localhost`، روی دامنهٔ شخصی و پشت هر ریورس‌پروکسی‌ای بدون یک خط تنظیمات کار
می‌کند.

پروکسی چیزی نگه نمی‌دارد، ولی سر راه است؛ پس خودت اجرایش کن —
[docs/PRIVACY.md](docs/PRIVACY.md) صریح دربارهٔ این معامله نوشته.

## ورود به حساب

**حساب‌ها** ← شماره موبایل را یک بار بالای صفحه وارد کن ← بعد برای هر پلتفرم فقط
کد پیامکی. حساب‌ها جدا هستند، شماره نه؛ پس یک بار پرسیده می‌شود و هر سه کارت با
همان وارد می‌شوند.

هر دو فیلد فقط رقم انگلیسی می‌پذیرند. شماره‌ای که با کیبورد فارسی یا عربی تایپ
شود (`۰۹۱۲…`) همان لحظه تبدیل می‌شود، به‌جای اینکه بالادست برود و «نامعتبر»
برگردد.

| پلتفرم           | ورود             | توکن برای چه لازم است     |
| ---------------- | ---------------- | ------------------------- |
| **اسنپ‌مارکت**   | برای نتایجش لازم | همه‌چیز                   |
| **دیجی‌کالا جت** | اختیاری          | فقط آدرس‌های ذخیره‌شده    |
| **اوکالا**       | اختیاری          | جستجو؛ فید تخفیفش باز است |

برنامه refresh token اسنپ‌مارکت را نگه می‌دارد، پس آن نشست خودش تمدید می‌شود.
توکن اوکالا ۱۰ ساعت اعتبار دارد و تمدیدشدنی نیست — سایت خودش هم دوباره لاگین
می‌کند، این هم همین کار را می‌کند.

کدها عمداً محدود شده‌اند: ۲ دقیقه بین دو کد، ۵ کد در ۱۵ دقیقه، ۵ تلاش برای هر
کد، و `Retry-After` سرور رعایت می‌شود.

## تنظیم موقعیت تحویل

**تنظیمات** ← **استفاده از موقعیت فعلی** برای GPS، یا مختصات را دستی وارد کن.
اگر به جت وارد شده باشی، آدرس‌های ذخیره‌شده‌ات هم همان‌جا لیست می‌شود.

## ساختار

```
app/            روتر اپ: پوستهٔ برنامه و یک پوشه برای هر تب
app/api/        پروکسی عبوری و health check — سمت سرور
src/api/        یک کلاینت برای هر پلتفرم؛ هرچه با شبکه کار دارد
src/core/       فید، جستجو، رتبه‌بندی، تطبیق فارسی — همه بدون I/O
src/auth/       نشست، محدودیت نرخ OTP، نرمال‌سازی شماره
src/routes/     کامپوننت پشت هر تب
src/server/     جدول مقصدهای پروکسی و قواعد CORS
public/sw.js    سرویس‌ورکر: فقط پوسته و تصویر، هرگز قیمت
docs/           معماری، اندپوینت‌ها، استقرار، حریم خصوصی، توسعه
```

Next.js 16 (App Router با خروجی standalone)، React 19، TypeScript، TanStack
Query و zustand. بدون فریم‌ورک UI: حدود ۷۰۰ خط CSS با توکن‌های طراحی، RTL، تم
روشن و تیره از سیستم، و نوار پایینی روی موبایل که روی لپ‌تاپ به نوار بالایی
تبدیل می‌شود. بدون دیتابیس، بدون حساب کاربری اختصاصی و بدون هیچ کلید مخفی.

## مشارکت

مفیدترین گزارش، تغییر شکل یک اندپوینت است — این‌ها APIهای مستندنشده‌اند و بدون
اطلاع عوض می‌شوند. [CONTRIBUTING.md](CONTRIBUTING.md) را ببین، و **هیچ‌وقت هدر
`Authorization` را جایی نچسبان**: آن توکن یعنی حساب تو.
