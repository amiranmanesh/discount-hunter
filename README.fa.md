<p align="center"><sub>یک جستجو، ۴۵ فروشگاه اطراف، مرتب‌شده بر اساس چیزی که واقعاً می‌پردازی.</sub></p>

---

کمپین `تخفیف نارنجی` اسنپ‌مارکت هم‌زمان روی ده‌ها فروشگاه اجرا می‌شود و یک کالای
مشخص در هر کدام تخفیف متفاوتی دارد. پیدا کردن بهترینش با دست یعنی باز کردن
فروشگاه پشت فروشگاه. این افزونه همه‌اش را در یک جستجو انجام می‌دهد و نتیجه را
جوری مرتب می‌کند که فروشگاهی که واقعاً باید از آن سفارش بدهی اول باشد.

پروژه‌ای مستقل و متن‌باز است و **هیچ** وابستگی، تأیید یا ارتباطی با اسنپ یا
دیجی‌کالا ندارد.

## چه کاری می‌کند

|                                     |                                                                                                                                                                                                                                         |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **کل قفسه را می‌خواند**             | همهٔ فروشگاه‌هایی که به آدرست ارسال دارند و در کمپین هستند را لیست می‌کند — حدود ۴۵ فروشگاه در تهران — بعد قفسهٔ **کامل** تخفیف نارنجی هر کدام را می‌خواند، نه آن ۱۰ کالایی که اندپوینت فهرست می‌دهد.                                   |
| **جوری مرتب می‌کند که خرید می‌کنی** | بیشترین تخفیف (در پله‌های ۵٪)، بعد فروشگاه‌های **پرو**، بعد کمترین هزینهٔ ارسال، بعد کمترین قیمت. دو ترتیب دیگر یک کلیک فاصله دارند.                                                                                                    |
| **قیمت‌های خودت را می‌آورد**        | با یک تب لاگین‌شدهٔ `snapp.market` از همان نشست استفاده می‌کند، پس هزینهٔ ارسال پرو و قیمت‌های شخصی‌سازی‌شده همان چیزی است که می‌بینی. بدون آن هم با توکن مهمان کار می‌کند.                                                             |
| **فقط قیمتی که می‌توانی بپردازی**   | فید کمپین تخفیف‌های `new_user` را قاطی می‌کند — هر تخفیف ۹۰ تا ۹۹ درصدی از همان‌هاست — که حساب قدیمی نمی‌تواند بخرد. این‌ها کلاً حذف می‌شوند (تنظیمی برای برگرداندنشان نیست) و قیمت نتایج اول با قفسهٔ خود فروشگاه راستی‌آزمایی می‌شود. |
| **نام یا کد کالا**                  | نام کالا را با پیشنهادهای خود اسنپ‌مارکت بنویس، یا کد کالا را بچسبان تا دقیقاً همان کالا را بین فروشگاه‌ها مقایسه کنی.                                                                                                                  |
| **فارسی درست**                      | یکسان‌سازی حروف عربی و فارسی، تبدیل ارقام، و تطبیق واژه‌ای — جستجوی `پفک مینو` بستنی دومینو نمی‌آورد.                                                                                                                                   |
| **دیجی‌کالا جت به‌عنوان منبع دوم**  | همهٔ فروشگاه‌های جت در محدوده را جستجو می‌کند و قیمت ریالی را به تومان تبدیل می‌کند. در نسخهٔ ۱.۰.۰ پیش‌فرض خاموش است.                                                                                                                  |
| **فروشگاه را باز می‌کند**           | هر نتیجه یک دکمه دارد که صفحهٔ همان فروشگاه را باز می‌کند.                                                                                                                                                                              |
| **هیچ چیزی جایی نمی‌رود**           | درخواست‌ها فقط به اسنپ‌مارکت و دیجی‌کالا جت می‌رود. بدون آنالیتیکس، بدون سرور ما، بدون وابستگی اجرایی. [docs/PRIVACY.md](docs/PRIVACY.md)                                                                                               |

## نصب

مرحلهٔ کامپایل ندارد — افزونه ماژول‌های ساده‌ای است که مرورگر مستقیم می‌خواند.

```bash
git clone https://github.com/amiranmanesh/discount-hunter-extension.git
cd discount-hunter-extension
```

```
chrome://extensions  ←  Developer mode روشن  ←  Load unpacked  ←  پوشهٔ extension/
```

### کدام مرورگرها

| مرورگر                                    | بسته                                          |
| ----------------------------------------- | --------------------------------------------- |
| کروم، اج، بریو، اپرا، ویوالدی، آرک (۱۱۱+) | `…-chrome.zip` — یک بسته برای همهٔ کرومیوم‌ها |
| فایرفاکس ۱۲۱+ و فایرفاکس اندروید          | `…-firefox.zip`                               |
| سافاری ۱۶.۴+ روی مک                       | با `npm run build:safari`؛ نیازمند Xcode      |

فقط کرومیوم روی نشست واقعی تست شده. جزئیات و نحوهٔ ساخت هرکدام:
[docs/BROWSER-SUPPORT.md](docs/BROWSER-SUPPORT.md).

برای ساختن بسته‌های آمادهٔ فروشگاه: `npm install && npm run package` و بعد
`release/discount-hunter-<version>-<target>.zip`.

### ورود به حساب

از پنل **حساب‌ها** در خود افزونه با شماره موبایل و کد پیامکی وارد شو، هر پلتفرم جدا.
**اسنپ‌مارکت اجباری است** — مهمان کمپین دیگری با قیمت دیگری می‌بیند، پس افزونه بدون
آن اصلاً جستجو نمی‌کند. **دیجی‌کالا جت اختیاری است**: جستجویش توکن نمی‌خواهد و ورود
فقط آدرس‌های ذخیره‌شده‌ات را اضافه می‌کند.

افزونه refresh token خودش را نگه می‌دارد، پس نشست خودش تمدید می‌شود و مثل توکن
قرض‌گرفته از سایت بعد از یک ساعت نمی‌میرد.

### موقعیت تحویل را تنظیم کن

هر قیمت و هزینهٔ ارسالی به مکان تو وابسته است.

- **راه ساده:** `snapp.market` را در یک تب باز کن و وارد حسابت شو. آدرس‌های
  ذخیره‌شده‌ات خودکار در پنل می‌آید؛ روی چیپ بالای پنل بزن و بینشان انتخاب کن.
- **دستی:** روی همان چیپ بزن و عرض و طول جغرافیایی را وارد کن. راست‌کلیک روی نقطه
  در گوگل‌مپ مختصات را کپی می‌کند.

## استفاده

نام کالا را بنویس — `پفک مینو`، `بستنی میهن` — و **جستجو** بزن. هر ورودی با چهار
رقم یا بیشتر به‌عنوان کد کالا در نظر گرفته و دقیق تطبیق داده می‌شود.

| کنترل                         | کار                                                                     |
| ----------------------------- | ----------------------------------------------------------------------- |
| **ترتیب**                     | نحوهٔ مرتب‌سازی — [docs/RANKING.md](docs/RANKING.md)                    |
| **فقط تخفیف کمپینی**          | روشن: فقط تخفیف نارنجی و شگفت‌انگیز. خاموش (پیش‌فرض): کاتالوگ معمولی هم |
| **فقط فروشگاه باز**           | فروشگاه‌های بسته را پنهان می‌کند                                        |
| **حداقل تخفیف**               | زیر ۲۰/۳۰/۵۰/۷۰ درصد را حذف می‌کند                                      |
| **اسنپ‌مارکت / دیجی‌کالا جت** | کدام پلتفرم‌ها جستجو شوند                                               |

روی هر کارت، جمع با ارسال و `حداقل سبد` فروشگاه نوشته شده. ترتیب‌بندی حداقل سبد
را حساب نمی‌کند، پس قبل از ذوق‌زده شدن برای بستنی ۵۰۰ تومانی، آن را ببین.

نمونهٔ واقعی، جستجوی `بستنی میهن`:

```
۹۹٪  ۵۰۰ تومان   دیلی مارکت سمنگان     ⚡ پرو · ارسال رایگان   → جمع ۵۰۰
۹۹٪  ۵۰۰ تومان   فروشگاه راکت سمنگان   ⚡ پرو · ارسال ۱٬۸۰۰    → جمع ۲٬۳۰۰
۹۹٪  ۵۰۰ تومان   سوپر.مارکت ونو        ⚡ پرو · ارسال ۲٬۰۰۰    → جمع ۲٬۵۰۰
```

پلهٔ تخفیف یکی، هر سه پرو، پس هزینهٔ ارسال تصمیم می‌گیرد.

## ساختار پروژه

```
extension/     خود افزونه — بدون build قابل لود است
  src/api/     یک کلاینت برای هر پلتفرم؛ همهٔ ارتباط شبکه اینجاست
  src/core/    ارکستراسیون جستجو، رتبه‌بندی، حذف تکراری
  src/util/    تطبیق متن فارسی، storage، اجرای هم‌زمان با سقف
  content/     برداشت نشست و موقعیت، یک فایل برای هر سایت
  popup/       کل رابط کاربری، RTL، سازگار با تم مرورگر
scripts/       build، manifest، آیکون‌ها و ابزارهای مرورگر خودکار
tests/         تست‌های Vitest روی core/، util/ و کلاینت‌های API
docs/          معماری، توسعه، رتبه‌بندی، حریم خصوصی، مرجع اندپوینت‌ها
site/          سایت GitHub Pages
wiki/          صفحات ویکی که موقع merge منتقل می‌شوند
```

[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) طراحی را توضیح می‌دهد و
[docs/api-notes.md](docs/api-notes.md) همهٔ اندپوینت‌ها و شکل داده‌ها را — که از
ترافیک واقعی ضبط شده — مستند می‌کند.

## توسعه

```bash
make install     # npm install + مرورگر Playwright
make verify      # چیزی که CI اجرا می‌کند: format، lint، تست، build
make browser     # کروم با افزونهٔ لودشده و نشست لاگین‌شده
make recon       # مرورگری که همهٔ کال‌های API را در probe-out/ لاگ می‌کند
make help        # همهٔ تارگت‌ها
```

هر تارگت `make` معادل npm script خودش را صدا می‌زند، پس هر دو کار می‌کنند.
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) ابزارهای مرورگر خودکار، ضبط ترافیک و
اضافه کردن پلتفرم را پوشش می‌دهد.

دو نکته که وقتت را می‌گیرد اگر ندانی: کروم منابع افزونه را در پروفایل کش می‌کند
(بعد از ویرایش، روی کارت افزونه reload بزن؛ به همین دلیل هر اسکریپت مرورگر خودکار
پروفایلش را اول پاک می‌کند)، و اسکریپت‌های انتها-به-انتها به API واقعی می‌زنند پس
عمداً در CI نیستند.

## مشارکت

مفیدترین چیزی که می‌توانی بفرستی، گزارش تغییر شکل یک اندپوینت است — این‌ها APIهای
مستندنشده‌اند و بدون اطلاع عوض می‌شوند. [CONTRIBUTING.md](CONTRIBUTING.md) را ببین،
و **قبل از چسباندن هر چیزی هدر `authorization` را پاک کن**: آن توکن یعنی حساب تو.
